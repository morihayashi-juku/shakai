# 中学社会 解いて覚えるプリント（元ファイル）

このブランチ（`source`）は、公開ページ（`main` ブランチ → https://morihayashi-juku.github.io/shakai/ ）を作るための元ファイル一式です。
公開ページそのものは `main` ブランチにあり、ここを変えてもサイトは変わりません。

## 新しいチャットで続きを作るとき（Claudeへのメモ）

1. このリポジトリを `source` ブランチで取得し、作業フォルダ（例：`/home/claude/shakai`）に置く。
2. `cp -r tools tmp` で作業用スクリプトを `tmp/` に戻す（スクリプトは `tmp/` にある前提で書かれている）。
3. 図を作り直すときだけ `npm install`（`node_modules` は保存していない）。
4. ビルド：`python3 build.py`（`pip install fonttools brotli` が必要）
   - `out/中学社会プリント.html` … 1ファイル版（パソコンでそのまま開ける）
   - `out/web/` … 公開用（図を4ファイルに分けて、1ファイル10MB未満）
5. 公開：`main` ブランチに `out/web/` の中身をコピーしてコミット・push。GitHub Pages が自動で更新する。
6. 元ファイルを変えたら、この `source` ブランチにもコミットしておく。

## ファイルの構成

| 場所 | 中身 |
|---|---|
| `template.html` | アプリ本体（画面・印刷レイアウト・スマホの読む画面）。`build.py` が単元・図・フォントを埋めこむ |
| `build.py` | ビルド。`FILES` に入れる単元の一覧がある |
| `units/*.js` | 単元データ。`geo01–21` 地理、`his01–19` 歴史（`his19` は年表）、`geo90`/`his90` 受験用総まとめ（12セット・解説つき）、`his04y–his07y` 中1向け「読んで解く」、`civ01–13` 公民 |
| `figs*.json`, `gen_figs*.mjs`, `gen_climate*.py`, `data/` | 図（SVG）と、その作成スクリプト・地図データ |
| `flows/` | 歴史各講の「この講の流れ」年表データ |
| `fonts/` | BIZ UDPゴシック等（SIL Open Font License） |
| `tools/yomu_data.py` → `tools/gen_yomu.py` | 「読んで解く」の本文と問題 → `units/hisNNy.js` を作る |
| `tools/yomu_gloss.py` | 「読んで解く」のむずかしい言葉の説明。各プリントで最初に出た所に「唐（中国の国の名前）」のようにカッコで入れる（中国・朝鮮の国名は自動） |
| `tools/gen_exam.js`, `tools/run_exam.py` | 受験用総まとめ（geo90/his90）を作る。最後に `add_ex.py` で解説をつける |
| `tools/ex_final.json`, `tools/exfix/`, `tools/merge_ex.py` | 総まとめの解説（自動抽出＋手直し） |
| `tools/*check*.py`, `tools/readtest*.py` | 印刷のはみ出し・答えの一致・スマホ表示の確認用 |

## 決まりごと

- サイトは「中1の宿題／中2の宿題／テスト対策／講座と問題」の4つに分かれ、最初は中1の宿題が開く。
- 宿題の一覧は `template.html` の `HOMEWORK`（新しい宿題はここに足す。中2はまだ空）。`build.py` の `FILES` にも単元を足す。
- 講座と問題の一覧は `template.html` の `SUBJECTS`。タグつき（`'まとめ'`, `'受験'`）は第N講の番号に数えない。
- 「読んで解く」：上半分に①②③の段落の本文、下半分に6問（穴うめ→一問一答→書こう→最後は紙を折って本文をかくして答える）。段落数は3→5へ増やし、各時代7枚＝7日分の宿題（1日1枚。近い内容の枚は MERGED でまとめた）。段落ヒントは 飛鳥=全問 / 奈良=穴うめと書こう / 平安以降=書こうだけ。答えはうら（両面印刷）か最後にまとめて。
- スマホ（幅700px以下）や `#単元ID` 付きURLは「読む画面」（問題だけ・パターン/セットを選べる・答えはタップで表示）。

## テスト対策ページ

- 左の一覧の「テスト対策」タブ。`HOMEWORK.test.parts` に「2026年11月　中2」のように、年・月・学年ごとのまとまりを新しいものから上に足していく。
- 単元IDは `tp年月+学年+種類`（例：`tp2611c2gy`＝2026年11月・中2・地理・宿題、`gj`＝地理・授業、`hy`/`hj`＝歴史）。見出しの「地理」「歴史」は単元データの `subject` のまま。
- 宿題：`tools/yomu2_data.py` → `tools/gen_yomu2.py`（中2「読んで解く」A4両面1枚）。
- 授業プリント：`tools/jugyo_data.py` → `tools/gen_jugyo.py`（A4両面・40分・図や表に書きこむ）。`［答え］`＝空らん、`［［答え］］`＝文で書く欄、`{{fig:キー}}`＝図。画面の「向け」で生徒用／先生用（答えが赤で入る）／先生用カンペを切りかえ。カンペは `jugyo_data.py` の `KANPE`（プリントの段落と同じ順番。説＝話す・問＝聞く→答え・板＝板書・注＝注意・テ＝テスト）。空らんの答えと時間（目安〇分の合計）は自動で入る。
- 確認：`tools/y2_check2.py`、`tools/jg_check.py`（はみ出しを見て、PDFを作る）。

## 暗記カード（`anki/`）

- 公開ページ：https://morihayashi-juku.github.io/shakai/anki/ （`main` ブランチの `anki/index.html`）
- `units/*.js` の「講座と問題」の問題（一問一答・記号選択・○×・説明・図の問題）を取りこんで、スマホで解く暗記カードにする。図のブロックとは別の所にある「地図１のA〜Fで…」のような問題には、同じプリントの図を自動で付ける。
- 図は `anki/f/キー.svg` に1枚ずつ分けて、問題を開いたときだけ読みこむ（全部で約20MB）。「〜Q」の図に「〜Label」の図があれば、答えのあとに「答えの入った図を見る」で出せる。
- ビルド：先に `python3 build.py`（`out/web/figs*.js` ができる）→ `node anki/build.js` → `anki/index.html` と `anki/f/` ができる。それを `main` の `anki/` にコピーしてpush。
- 4択モードの選択肢は、同じ分野の一問一答の答えから、聞き方（だれ・どこ・何年など）と答えの終わり方が近いものを自動で選ぶ。並べかえ・説明問題は「めくって答える」だけ。
- みんなで使うので、覚えた・まちがえたの記録は残さない（その回の「まちがえた問題をもう一度」だけ）。端末に残るのは、選んだ講と設定だけ。
- 公民（civ）の単元ができたら、自動で「公民」タブができる。
- 理科の問題は `anki/rika/rika1.txt`（中1）〜`rika3.txt`（中3）に、1行1問で書く。
  - `@sci01|中1 生物|生物の観察と分類` … 単元の始まり
  - `k|問題|答え` … 一問一答（4択モードでは、ほかの答えから選択肢を自動で作る。問題文に「（高い・低い）」があればその中から選ぶ）
  - `m|問題|正解|ちがう選択肢|ちがう選択肢…` … 選択問題（正解を最初に書く。表示するときに並べかえる）
  - `t|文|○` … ○×問題

## 公民（civ01〜civ13）

- 地理・歴史と同じ形（講座＋問題6枚・パターンA〜D）。単元データは `units/civNN.js` に直接書いている。
- 図：`python3 tools/gen_figs_civ.py` → `figs_civ.json`（説明用 `〜Label` と問題用 `〜Q`。Pythonだけで作れる）。
- 確認：`python3 tools/civcheck.py civ01 civ02 …`（ページの余白・縮小・パターンごとの答えの一致、`tmp_civ/` にPDF）。
- 講座のページ分け：`python3 tools/civ_repack.py civ02 3,3`（section を前から3つ・3つのページに分け直す）。
